Our Vision & Team

一緒に、未来の架け橋を
架けませんか？

NextBridgeは、平均年齢31歳、エンジニア・デザイナー・カスタマーサクセスが緊密に連携するフラットで自律的なチームです。

私たちは「プロダクト主導の成長（PLG: Product-Led Growth）」を大切にしています。機能の多さだけでなく、現場のユーザーが直感的に使えて感動するUXを追求すること。それが私たちの誇りです。

フルフレックス・ハイブリッドワークなど柔軟な働き方を整え、互いを尊重しながら最速で成長できる環境をご用意しています。あなたの知的好奇心とパッションを、ここで存分に発揮してください。

フロントエンドエンジニア

仕事内容

自社SaaS（BridgeCRM, BridgeFlow, BridgeAnalytics）のフロントエンド設計・実装をご担当いただきます。コンポーネント設計、パフォーマンスチューニング、デザインシステム運用をリードしていただきます。

必須スキル・経験

  • TypeScript, React または Vue.js / Next.js によるWebアプリケーション開発実務経験（3年以上）
  • HTML5 / CSS3 (Sass, Tailwind CSS) によるレスポンシブUI実装スキル
  • Git / GitHubを用いたチーム開発およびコードレビュー経験

歓迎スキル

  • Webパフォーマンス改善やアクセシビリティ（a11y）に関する知識
  • Design Systemの構築・運用経験
  • GraphQL / REST APIの設計・連携経験

待遇・条件

想定年収：550万〜900万円（経験・能力を考慮の上決定） / フルフレックス（コアタイムなし） / リモートワーク可（週2〜3日出社推奨）

選考プロセス：書類選考 → カジュアル面談 → 一次面接（技術） → 最終面接 この職種に応募する
開発部門 正社員 / ハイブリッドワーク

バックエンドエンジニア

仕事内容

高可用性・拡張性を備えたAPIサーバーの設計・開発、マイクロサービス化の推進、大量データを高速処理するデータパイプライン基盤の構築をお任せします。

必須スキル・経験

  • Go, Python, TypeScript (Node.js) のいずれかを用いたWebバックエンド開発実務経験（3年以上）
  • RDB（PostgreSQL / MySQL）のスキーマ設計およびクエリ最適化スキル
  • AWS または GCP を用いたクラウドインフラの構築・運用経験

歓迎スキル

  • コンテナ技術（Docker / Kubernetes）の運用経験
  • 大規模トラフィック・大容量データの分散処理設計経験
  • セキュリティ対策（OAuth, JWT, 暗号化など）の実装経験

待遇・条件

想定年収：600万〜1,000万円（経験・能力を考慮の上決定） / フルフレックス / リモートワーク可

カスタマーサクセス (CS)

仕事内容

導入企業へのオンボーディング支援、活用促進、チャーン（解約）防止施策の企画・実行、アップセル・クロスセルの提案を行います。顧客の声を開発チームへフィードバックする要のポジションです。

必須スキル・経験

  • BtoB SaaS企業でのカスタマーサクセス実務経験（2年以上）、またはIT業界での法人営業/コンサルティング経験
  • 顧客の業務課題を構造化し、解決策をわかりやすくプレゼンテーションできる高いコミュニケーション力
  • 数値目標（NRR, 解約率など）への強いコミットメント

歓迎スキル

  • CRM/SFA/BIツールの導入・運用経験
  • コミュニティ運営やセミナー（ウェビナー）登壇経験

待遇・条件

想定年収：500万〜800万円 / フルフレックス / リモートワーク可

選考プロセス：書類選考 → カジュアル面談 → 一次面接 → 最終面接 この職種に応募する
デザイン部門 正社員 / ハイブリッドワーク

UI/UXデザイナー

必須スキル・経験

  • Figmaを用いたWebサービス・アプリのUI/UXデザイン実務経験（3年以上）
  • ユーザーリサーチ、ジャーニーマップ作成、プロトタイピングの経験
  • ポートフォリオの提出が可能な方

歓迎スキル

  • デザインシステムの構築・運用経験
  • フロントエンド（HTML/CSS/JS）の基本的な理解
  • BtoB向け複雑な業務ツールのUI設計経験
